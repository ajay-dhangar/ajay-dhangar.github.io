## Overview

JavaScript Mastery is a learning platform for developers who want to get better at JavaScript. It combines tutorials, coding challenges, and projects so learners can move from reading to building.

## What it offers

- Tutorials that explain core JavaScript concepts
- Coding challenges for practice
- Projects that put the concepts to work

## How it's built

The site uses React and TypeScript with Docusaurus, which keeps tutorials easy to organize and update.
