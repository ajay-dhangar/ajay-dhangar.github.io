## Overview

Algo helps developers learn and practice data structures and algorithms. Instead of only reading about a concept, learners work through interactive coding challenges.

## What it offers

- Data structures and algorithms explained in a learning-first format
- Interactive coding challenges for hands-on practice

## How it's built

Algo uses React and TypeScript with Docusaurus as the content framework, so lessons stay easy to write and maintain. The code lives in Git.
