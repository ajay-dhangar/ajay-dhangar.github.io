## Overview

AI Buddies is a space for developers to learn and practice AI. It pairs tutorials with hands-on projects so concepts turn into something you can run and change.

## What it offers

- Tutorials that introduce AI topics
- Hands-on projects for practice

## How it's built

The site is built with React and TypeScript on Docusaurus, using the same content-first setup as my other learning platforms.
